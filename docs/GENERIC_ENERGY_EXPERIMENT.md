# 从自然语言到目标／约束能量：通用闭环实验

## 结论与实现范围

用户提出的方向是合理的：让 LLM 理解目标和约束，让 p-bit 搜索变量，而不是要求 LLM 先生成一条完全可行的路线。仓库新增独立的 `qihc/generic` 路线，不替换原 CVRP 实验。

两个 LLM 调用分别输出：

1. 变量数量、目标方向、线性／二次目标系数；
2. 原始硬约束的线性表达式，以及受限的惩罚／温度策略。

统一编译器将表达式展开为惩罚能量、QUBO 和 Ising 参数。LLM 不直接运行 Python/C++，也不被允许通过省略约束来改善执行奖励。每次建模只调用两次 LLM；之后统计反馈在搜索器内部运行，不需要每一步调用模型。

**本版支持：二元变量、整数系数的线性等式／不等式、线性或二次目标。不是任意自然语言问题的无条件通解。** 软件限制为 96 个原变量、128 条约束、编译后 512 位；未知运算、维度不一致、过大表达式直接拒绝。连续变量、一般非线性、任意逻辑量词、复杂路径连接性需要额外的通用表达式和编译规则，不能靠文字宣称已经支持。

## 能量推导

设 x∈{0,1}^n，最小化目标为 f(x)；最大化时取负。约束为 a_j·x≤b_j、≥ 或 =，系数为整数。

- 对 ≤：引入非负整数松弛 s_j，P_j=(a_j·x+s_j−b_j)²。
- 对 ≥：P_j=(a_j·x−s_j−b_j)²。
- 对 =：P_j=(a_j·x−b_j)²。

松弛上界不是让模型猜：≤ 使用 max(0,b_j−Σmin(0,a_ji))；≥ 使用 max(0,Σmax(0,a_ji)−b_j)。使用权重和恰好等于上界的有界二进制编码，例如上界 5 对应 [1,2,2]，确保每个编码都在允许范围、范围内每个整数均可表示。重复表示是允许的，不改变最优能量的对应关系，但可能影响有限温度的采样分布。

令 B=max(1,Σ|目标线性系数|+Σ|目标二次系数|)，则 f/B 的值域宽度不超过 1。构造

    E(x,s) = f(x)/B + Σ λ_j P_j(x,s)

若原问题存在可行解，并且每个 λ_j>1，那么在精确算术下，任何不可行状态至少产生一个 ≥1 的整数平方残差，因此不能成为全局最低能量状态。这是**全局最优解的充分条件，不是有限时间搜到可行解的保证**。

固定策略使用 λ=2；反馈策略允许早期小惩罚探索，依据每条原约束在种群中的违反率逐块调权，增幅受限、上限为 8，在最后阶段将权重至少提高到 2。目标／约束结构始终不变。保存历史最优时用“可行性、违反量、原目标”排序，不跨不同惩罚权重比较总能量。

QUBO 采用 E=zᵀQz+c 的对称矩阵约定。令 z=(s+1)/2，可输出 E=−½sᵀWs−hᵀs+offset，其中 W 对角线为零。单元测试逐状态检查直接表达式、QUBO、Ising 三者一致，并穷举检查可行性／惩罚间隔。

## p-bit 搜索与反馈

初态是随机比特，可以不可行；没有问题专用的构造、修复或邻域。每条独立链每一步更新一个随机位置：

    Pr(z_i=1 | z_-i) = sigmoid(−[E(z_i=1)−E(z_i=0)] / T)

仅在独立副本间并行，不同时更新存在耦合的位。固定参数时这是单点热浴条件更新；温度退火和反馈调权期间是非平稳搜索，不能宣称始终服从同一个平衡分布。本版用 CPU float64 模拟，GPU 用于 LLM 推理／训练，尚非 FPGA 实测。

继承的是闭环分工和训练接口，不是 CVRP 专用实现：

- 搜索反馈：每条约束违反率 → 有界惩罚调度 → 后续采样；
- 训练反馈：多个策略在相同问题、相同预算下执行 → 跨种子偏好 → SFT/DPO；
- 不直接复用原 CVRP 的路线修复和 GRPO 奖励。本版没有通用 GRPO，也没有在线额外 LLM 自改约束的回路。

每条约束可以由同一个通用解释器验证，不必为背包／覆盖／分配分别写检查器。但 LLM 错译约束后，该解释器只能证明“符合错译模型”，不能证明符合用户原意。因此基准评测另有隐藏 gold IR。实际部署仍需建模校验、人类确认或独立语义审查；第二个 LLM 不能自动成为可靠证明器。

## 后训练到底训练什么

SFT 使用生成器的正确数学表达式，学习自然语言→目标／约束的结构化建模；这是有监督数据，不包装成 p-bit 自己发现了语义。

p-bit 在每个训练问题上比较 fixed/adaptive/warm/cold 四种策略。前两个种子先按可行次数、再按平均奖励排名，第三个种子独立确认；胜者必须三个种子全部可行，且排名与确认间隔均超过阈值，才生成 DPO 对。chosen 和 rejected 的约束完全相同，仅策略不同，阻断“删约束降低成本”的奖励漏洞。训练前重新检查数据划分、提示词一致性、目标／约束语义和执行证据。

因此当前 DPO 的能力目标是**学会根据问题选择执行策略**，不是自由生成任意惩罚函数。它是可验证的第一阶段；后续可以扩展到更丰富、带编译证明义务的惩罚模板。三个种子只是降低偶然性的措施，不构成统计显著性证明。

训练顺序：SFT → 带 chosen-answer NLL 正则的 DPO，参考策略冻结为 SFT。复用现有真实 LoRA 训练器。DPO 继续更新同一个 adapter，推理只加载最终 adapter，不能叠加一次 SFT 再叠加 DPO。偏好不足 16 对则明确标记 `complete_without_dpo`，不会伪造训练样本。

|训练|单 H100；BF16 LoRA rank16；微批1、累积4；上下文16384；SFT≤128步、DPO≤64步，并按数据量限制约一遍|
|时间限制|默认 36 小时，失败／超时保留已写结果，不宣称保证完成|

这些是机制验证规模，不是大型真实业务 benchmark，也不是已经证明顶会贡献。更大规模需要检查编译位数、长约束输出可靠性以及单点搜索的混合速度，而不是只增加客户数。

对照分两层：

1. **正确模型层**：CP-SAT、随机扫描公平比特、Metropolis、固定惩罚 p-bit、反馈 p-bit、关闭反馈的匹配 p-bit。随机对照是每一步重抽一个比特，不是每一步独立重抽整个解。所有采样方法使用相同比特更新预算；CP-SAT 使用独立时间预算，所以不能据此直接宣称等成本获胜。
2. **自然语言端到端层**：纯 LLM 直接输出 x；base/SFT/DPO 先建模再 p-bit 搜索。每种建模结果另外跑固定策略对照、关闭反馈的匹配消融和 **同一 LLM 建模 + CP-SAT**。固定策略同时改变初始权重，不是单独识别反馈效果的消融；`_no_feedback` 保留原策略的初始权重、退火和末段加硬，仅关闭违反率驱动的调权。CP-SAT 不能偷偷拿 gold 替换模型错译的约束。

完整记录真实约束可行率、保守的建模结构匹配率、可行目标、已证最优实例上的 gap、调用次数、输入／输出 tokens、搜索时间和失败数。结构匹配可能拒绝代数等价表达式，因此不是完备语义判定。失败样本计入分母；不同可行子集的目标均值不能单独用来判断改进。`comparison.json` 给出同实例／同种子配对结果，以及以实例为单位的 `case_paired_vs_base`，让无随机种子的 CP-SAT／直接 LLM 也参与比较，避免把同一个实例的多个种子当作独立实例。

采样使用分离的初态、更新位置、随机抽样三个随机数流；同一编码／种子下各方法共享初态和更新位置，避免随机数消费方式造成隐性差异。CP-SAT 的 `seconds` 包含建模与求解，另留 `solver_seconds`。汇总同时报告搜索时间、包含 LLM 建模的时间和去重的物理调用成本。**当前是等比特更新预算的采样对比，不是所有方法等墙钟时间、等 token 或等能耗的比较。**

## 与现有工作的关系及可主张的方向

自然语言→优化建模→求解已有 [OptiMUS](https://arxiv.org/abs/2402.10172)；用平方罚项把组合问题转为 Ising/QUBO 已有 [Lucas 的综述](https://arxiv.org/abs/1302.5843)；p-bit 的硬件随机计算也已有 [随机磁隧道结实验](https://www.nature.com/articles/s41586-019-1557-9)。所以不能把“LLM + 罚函数 + p-bit”这个组合本身宣布为全新且足够的顶会贡献。

值得实证检验的贡献候选是：**受限且可检查的能量编译、违反结构驱动的反馈策略、利用随机执行分布后训练策略，以及有限精度硬件上的跨问题成本／质量收益**。本次代码提供前面三项的实验基础，最后一项仍需要 FPGA 实测和更强基线；不能预写胜利结论。

## 128 位 INT8 真机的关系

先看编译后的总位数，不只看原变量数；本版软件上限 512 不是向硬件提出 512 位要求。能量编译器已能输出 W、h、offset，但没有连接 FPGA、没有做 INT8 等价性认证。

全局正比例缩放在精确算术下不改最优状态，但舍入到 INT8 会改变罚项间隔。若所有状态上的量化能量误差绝对值≤ε，则维持上述可行性间隔的充分条件是 2ε < min(λ)−1；该界可能很保守，却说明不能只说“缩放后肯定够”。硬件阶段还应报告系数动态范围、舍入误差、可行率退化和端到端能耗（包括模型、CPU 与通信），而非仅芯片功率。
