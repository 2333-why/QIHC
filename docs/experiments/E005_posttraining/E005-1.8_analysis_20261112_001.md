代码`report.py`中恢复条件是initial_status=invalid且最终compiled，未要求verified_correct；退化条件是verified_correct→disproved，未包含正确→invalid/unknown。两列既不对称，也不能相减为净正确修复。分母是全部评价轨迹，缺少初始无效/初始正确总数，不能计算条件修复率和退化率。

所有组“局部补丁接受=0”是报告统计decision=accepted。后训练worker直接生成或复用模型，不走feedback.decide；pair_local的训练局部修复在training.py中写入trace/*.json的verified与samples.edit_status。因此此列在train作业不能诊断局部蒸馏是否成功，不能推断训练修复次数为0。

## 历史比较与限制

1. E005-1.7曾仅配齐P-VCD主测216题，p-bit最优85.0%；此次配齐480题为50.8%。样本组成改变，不能解释为模型性能从85%崩到51%。此次共同全题应取代旧子集的总体排序，旧子集证据保留。
2. 本次SFT规模p-bit最优29.0%，历史E005/SFT为29.3%；P-VCD为28.8%对历史28.5%。当前score.py按题与模型缓存，并用20秒墙钟求解预算。可能存在重评分、计时或调度差异；根因须比对manifest与逐题cross求解记录。小于1个百分点的跨轮差异不宜直接归因于训练。
3. 规模SFT对E004 P2的p-bit最优为29.0%对22.0%（+7.0），完整正确24.0%对18.3%（+5.7）；相对C0最优+5.3。C0只有每题1种子而其他组2种子，虽均按题等权，种子覆盖不同。主要收益仍体现为SFT系统相对旧系统的改善，不能声称等算力因果比较。
4. 历史能量四组规模最优21.2%，比本次SFT低7.8；主测48.8%比SFT高0.8。此次未新训练能量组，不算独立重复验证，也不支持轨迹输入独有收益。
5. 主测unknown仅0.2%–0.4%，完整正确却约38%–40%；低完整正确不能主要归咎unknown。精确的invalid/disproved分布仍需逐题数据。
