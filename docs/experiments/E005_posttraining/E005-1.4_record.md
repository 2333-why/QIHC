# E005-1.4 四方法后训练及 E004 同题对照

2026-11-07（Asia/Shanghai），代码已构建，服务器训练待运行。本迭代从 [P-VCD 设计](E005-1.3_plan.md)的提交 917705ff 建立分支 codex/e005-four-methods。工作目录与正在运行的反馈实验独立，运行命令见[实验入口](../../experiments/posttraining_v1/README.md)。运行时以 CPU 准备清单冻结模型、包版本和源码。运行根目录为 /inspire/hdd/global_user/czxs25210022/why/results/E005-1.4_four。

| 后训练方法 | 本轮实现 |
|---|---|
| SFT | 题面到公开标准 IR 的答案 token 监督 |
| Solver-RL | 同一 SFT 出发，每题四候选，以 SCIP 结果在原题上的可行和最优命中给分，非法模型负分；单步组相对策略梯度 |
| SDPO-IR | 同一 SFT 出发，使用编译或训练语义检查的文字反馈，同一策略作为停止梯度教师，按当前采样轨迹计算学生到教师的逐 token KL |
| P-VCD | 同一 SFT 出发，p-bit 条件采样 → 独立验证赋值反例 → 教师生成修复 → 等价性验证 → 对已证正确修复进行 NLL 和教师 KL 蒸馏，同时对有区分度的已知语义奖励组更新策略 |

四组均使用同一 Qwen3-32B 与 E004_2.2 初稿提示。SFT训练3遍，其余各2遍，按固定步数取最终模型。后续三组各自继承同种子的 SFT。每组共享训练题答案锚点。Solver-RL 和 SDPO 是统一 IR 下的适配。P-VCD 为首个四组实现：每轮最多2个可编译候选，每候选20秒p-bit探针，32链、三个温度，20%随机探索；门控使用既有离线等价验证器，无法判定的修复记unknown。路径明确且发生变化的目标或约束节点权重2，无法唯一定位时权重1。格式失败保留。教师修复轨迹使用教师强制训练，组相对策略更新每批只做一步，旧策略就是更新前当前策略。各方法训练实际计算量不同，steps与trace记录分项，不能声称相同训练成本。

为复用反馈实验的运行环境，选用 BF16 单卡冻结基座，q/v 投影自包含 LoRA，rank16、缩放2、dropout0，四卡并发独立方法/种子。单题一优化步、梯度裁剪1，SFT学习率2e-5，余组5e-6。使用既有 Transformers 推理，不增加训练框架依赖。正式实验三种子17/29/43。首轮四组没有同损失的 SCIP 反例训练消融，单独归因于 p-bit 需要后续对照。

## 数据及比较
