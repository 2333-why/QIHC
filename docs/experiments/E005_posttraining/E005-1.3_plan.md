# E005-1.3：p-bit 主动反例驱动的验证式后训练

2026-11-07，Asia/Shanghai。状态：方法设计完成，代码待实现，尚无训练结果。替代未执行的 [E005-1.2](E005-1.2_plan.md)，保留历史方案和[文献清单](E005-1.2_literature.md)。

方法暂名 **P-VCD：p-bit-guided Verified Counterexample Distillation**（p-bit引导的验证式反例蒸馏）。名称仅为本项目工作名，尚未完成名称/新颖性穷尽检索，不声称首创或已证明优势。

## 1. 要解决的问题

普通SFT告诉模型正确答案，结果奖励RL告诉模型成功或失败；我们希望额外告诉模型：哪个约束或目标关系被具体赋值推翻，应该优先学习哪部分修复。训练后主测只输入题面，不再调用p-bit探针，检验这种诊断能力能否转入模型参数。

贡献假设不是把几个已有损失相加，而是“预算内主动选择反例→证据验证→结构化定位→选择性蒸馏”的联动机制。p-bit用于产生有诊断价值的候选赋值，不充当真值验证器，也不用于直接训练硬件权重。

| 借鉴路线 | 保留的思想 | 我们提出的改动 |
|---|---|---|
| SDPO | 反馈条件教师给学生密集监督 | 用独立验证的反例卡片替代泛化文字评论，并验证教师修复后才开启修复蒸馏 |
| SIRL / OMSO | 可执行环境提供训练信号 | 训练奖励明确区分已证正确、已证错误和未知，不将求解成功等同完整建模正确 |
| SAGE | 不同输出段可以承担不同学习权重 | 将权重落实到反例对应的IR路径/修复段，而不是泛化的策略段 |
| p-bit主动反馈 | 多温度、条件钳制、多链产生候选赋值 | 按独立窗口中的新有效反例产出调度探针预算，记录弃权并限制噪声传播 |

这是受上述方法启发的新组合设计；下述修复轨迹蒸馏使用离线/滞后轨迹，不称SDPO原版的on-policy目标。SDPO原版适配仍作为独立对照。

## 2. 一次训练迭代

1. **生成模型**：当前策略每题生成4份完整IR，同组共享题面、输出上限和格式协议，保存采样策略版本。固定变量ID/顺序，无法安全对齐到标准模型的候选标unknown，不猜映射。
2. **初步判断**：解析、编译、代数等价证明/小域穷举/已知反例检测。格式失败由确定性解析诊断进入格式恢复记录，不伪称p-bit发现；最多选择2份可编译、未证正确的候选进入探针。
3. **主动探针**：用p-bit在多温度与条件钳制动作下产生赋值。动作首轮均匀探索，用独立确认窗口检验后，优先分配给每CPU秒新有效反例较多的动作，保留20%探索预算；统计复现次数只表示搜索稳定性，不解释为语义正确概率或收敛证明。
4. **独立验证**：对采样赋值在原变量空间重新计算标准模型和候选模型的约束/目标，反例须被确定性验证器确认。辅助QUBO能量不能直接当原题可行性。只保留去重后最多4条卡片；无有效证据则弃权。
5. **教师修复**：使用当前采样轮冻结的策略快照，输入题面、错误IR和已验证卡片，生成一次完整修复。独立验证修复是否已证等价；只修好一条卡片但整体unknown不能晋升为正样本。不在卡片中复制完整gold IR。
6. **训练更新**：已证正确修复参与结构化蒸馏；原始rollout参与可验证奖励更新；固定训练集SFT样本提供防遗忘锚点。保存每个损失分量、有效样本数与计算成本。

所有gold访问只允许训练划分的探针/标签程序与最终独立评分器。训练阶段允许标准模型参与反例验证，必须明确这是有监督训练环境，与E004的无gold在线反馈设定不同。测试生成进程看不到gold、卡片或标准最优值。

## 3. p-bit反例与预算调度

| 反例 | 可核查证据 | 能说明什么 |
|---|---|---|
| 约束遗漏/过松 | 某赋值候选可行、标准不可行 | 候选接受了不应接受的解 |
| 约束过强 | 某赋值标准可行、候选不可行 | 候选排除了合法解 |
| 目标关系错误 | 两个共同可行赋值在两模型中的严格优劣关系相反，或并列关系不一致 | 目标方向/系数关系不等价 |

小整数模型优先精确运算；浮点需要固定可行性/目标容差，容差内冲突不作证据。不可行域、常数目标和变量重参数化需专门处理，未实现则unknown。完整等价判定沿用项目的可行域与目标排序口径，不把字符串完全一致作为唯一标准。

拟复用现有温度0.25/0.5/1、32链与钳制动作框架，每个候选探针总预算20 CPU秒（包含探索与确认），单题最多40秒。有效反例是重新验证的赋值，来自一个窗口即可在数学上成立；跨窗口确认用于调度稳定性与去重，不把低频真实反例删成假证据。反例跨轮只在当前候选IR哈希相同时重用，防止旧证据污染新模型。

## 4. 训练目标（待实现的明确算法）

总损失初始形式：

`L = L_VRL + 0.5 L_VCD + 0.1 L_anchor + 0.02 L_ref`

系数是初始工程设置，不是已验证最优参数；仅可用验证集一次小范围选择并在测试前冻结。所有分量先按有效token/轨迹归一化，避免因输出长度或有效样本数改变隐含权重。

### 4.1 验证式奖励更新 L_VRL

对原始4条rollout，已证正确r=+1，已证错误或确定格式非法r=-1，unknown不参与奖励均值/方差，也不获得正奖励。有效子组至少2条且奖励有差异时使用裁剪组相对策略梯度，否则此项为0。记录known覆盖率和组内有效数，避免把验证容易的题当全分布。

初始clip=0.2，温度和生成设置按对照统一冻结。更新只使用本轮采样策略和保存的旧logprob；跨轮旧轨迹不直接充作on-policy数据。采用此unknown过滤是本方法设计，与原生GRPO有差异，必须在论文和适配实现中披露。

不奖励“求解很快”或较低p-bit能量，防止模型删约束投机；求解效率先作为外部指标。没有奖励方差时不伪称有效RL更新，转由已验证修复与SFT锚点提供学习信号。

### 4.2 验证式修复蒸馏 L_VCD

仅在修复y+已证正确、反例有效时开启。固定本轮教师参数，不反向传播；教师上下文为题面x、原尝试y和卡片C，学生上下文只有x。

在同一修复前缀y+_<t上计算：

`q_t = stopgrad(p_teacher(. | x, y, C, y+_<t))`

`p_t = p_student(. | x, y+_<t)`

`L_VCD = mean_t w_t [ -log p_t(y+_t) + 0.5 KL(q_t || p_t) ]`

这是经验证修复序列上的教师强制蒸馏，属于off-policy修复蒸馏，不声称等价于SDPO原版。验证的是y+这条完成序列，并不保证教师全部词表概率都正确，因此保留已验证答案的NLL锚定，并监控KL项是否带来退化。

权重w_t：错误IR与修复IR作AST差分，受验证反例涉及且发生修改的IR路径初始权重2，其余1，再按序列归一化到均值1。先做稳定JSON序列化，通过字节跨度与token offset映射标注；不能直接将旧输出token位置套到新输出。新增遗漏约束可由新增节点定位；无法唯一归因或多个等价修复时退回均匀权重，不编造“因果定位”。整个输出仍有监督，避免只学局部而破坏其他字段。

不截取损坏的JSON，不静默丢失目标或约束。词表KL按时间分块计算以控制显存；若改为top-k近似需记录近似与校验，不把它称为精确KL。

### 4.3 稳定性与弃权

L_anchor来自固定训练题标准IR的completion-only NLL，所有受控方法可见相同训练监督；L_ref在相同上下文/前缀上约束学生偏离冻结SFT参考策略。教师、参考与学生可通过共享冻结基座+独立LoRA快照顺序前向实现，不默认同时常驻三份32B权重；必须实际测量显存。

unknown修复不进入VCD；全组无有效奖励、无已验证修复时只做anchor并记录“无新信号”。已证正确原模型不强制修复；若修复把正确模型变坏，该负例保留用于诊断，不能作为正教师。避免靠重复采样无限寻找通过样本，严格执行每题上限。

## 5. 最小但充分的对照

为避免训练组无限增加，主表保留六组，并将之前DPO路线降为小规模方法选择消融。

| 组 | 训练方法 | 回答的问题 |
|---|---|---|
| B | Base | 原始能力 |
| S | SFT | 基础监督收益 |
| R | 求解器结果奖励GRPO适配 | 标量奖励路线的效果 |
| D | SDPO-IR适配 | 通用文字反馈蒸馏的效果 |
| X-VCD | 完整P-VCD算法，仅p-bit探针替换成SCIP主动反例搜索 | 同损失、同验证器下反例来源是否有效 |
| **P-VCD** | 完整方法 | 总体建模与解质量收益 |

X-VCD与P-VCD共享起点、动作/卡片格式和CPU预算上限，SCIP可用原生搜索实现动作，不将p-bit特定数值参数强套到SCIP；比较新有效反例覆盖率、修复成功率和最终性能。R/D/P的奖励或监督信息量不同，单列训练信息权限和成本；不能把总方法差异全归因于某一损失。

SAGE仍保留为扩展对照；OMSO继续优先核实原版实现，PEARL/OR-R1保留独立交互/测试适配轨道。Metropolis已删除，不恢复为必跑组；没有该对照就不宣称p-bit内核相对普通采样的特异性优势。

固定60训练题和30验证题先做三项消融（均不接触测试）：

- P-VCD去掉主动预算分配：保持p-bit、动作集合和总预算，只均匀分配，检验主动调度。
- P-VCD去掉反例定位加权：w_t全为1，检验结构定位。
- p-bit-DPO替代VCD联合目标：相同候选/证据来源与资源上限，判断新学习方式是否优于之前的离线DPO。

验证门控是基本正确性要求，不通过故意喂已知错误正标签来做不必要的正式消融。直接统计门控拒绝率及“仅卡片修复成功但全局仍错”的比例。小规模消融只能支持探索性判断；若用于论文核心机制结论，应按预定规模扩展并冻结新的独立评价，不把30题结果写成正式主结论。

## 7. 评价与可证伪条件

主指标：全题分母的已证完整建模正确率；同时报告已证错误/unknown、规范化前后格式成功、原题可行率、已证最优命中及成本。gap只在共同可行且有已证参考的子集上计算，并展示子集题量。模型失败不得计为求解器本体失败。

P-VCD相对X-VCD/R/D为三项主要配对比较，按原题聚类bootstrap、种子题内平均、95%区间及Holm校正。主测不调用反馈、不更新权重。每份IR冻结后给同预算两后端；统计原题数420而非1260独立样本。

额外诊断：有效反例/CPU秒、约束错误类别覆盖、unknown率、已验证修复率、有效RL组比例、证据→IR路径定位成功率、正确模型退化、分族和规模泛化。

- 若P-VCD仅提高JSON成功而不提高语义/原题可行率，不支持语义学习贡献。
- 若P-VCD不优于X-VCD，不支持p-bit相对经典反例的优势。
- 若均匀调度相当，主动预算机制未显示额外收益。
- 若仅S/M提高而L退化，不宣称强规模泛化。
- 若验证器覆盖不足，保留unknown并缩小结论，不把无反例作为成功。

## 8. 文献依据与原创边界

[SDPO全文](https://arxiv.org/html/2601.20802v2)提出反馈条件自教师及密集蒸馏，也讨论与GRPO结合；因此“蒸馏+RL”本身不是我们的新颖点。[SAGE全文](https://arxiv.org/html/2605.02545v1)提供策略分段与加权训练思路；我们的结构路径加权是待验证的变体，不能声称由该论文验证。

[SIRL](https://arxiv.org/abs/2505.11792v3)与[OMSO v2](https://arxiv.org/abs/2604.00442v2)已覆盖求解器反馈后训练。候选贡献应限于：预算感知的p-bit反例获取、证据约束的教师修复门控，以及反例到IR路径的训练信用分配。先完成实现、消融和更全面相关工作核对，再判断是否足够构成论文创新。
