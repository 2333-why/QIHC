## 先测冻结方案

以同一固定降温预算下的已测命中数选定建模起点。NLCO 使用旧局部加权，已知 286/780。DCP-Bench 使用 E005-1.18 增广建模，已知全量 22/235、主测 12/159，主测三个搜索种子均值 7.13%。NLCO 历史 P-VCD 的 20 秒结果采用独立预算，补齐同固定降温预算的 P-VCD 后再比较。两套数据集中分别报告最高观测命中及并列组。

- 同一建模起点下评测直接求解、仅修编译 B、修编译加无采样双复核 C、前序多能量 p-bit 反馈四组。终端为固定降温 p-bit 和 SCIP。前序候选、预测及在同模型同预算下已有的逐题评分直接复用。若 B 与 C 处理同一无效初稿，共享一次修编译。
- NLCO 加入同接口和预算的无适配器、SFT、Solver-RL、SDPO、P-VCD，分别用固定降温 p-bit 和 SCIP。旧档中四种后训练各有 780 份 seed-17 预测，完整预测直接读入。SCIP 沿用 E005-1.7 每题终端种子和 20 秒带记录口径，并读取匹配模型的缓存。NLCO 的七个传统后端以 E003-1.1 的标准模型结果为参考，另纳入旧无反馈、无后训练的 LLM 模型轨道。两个 E003 轨道均为 20 秒、seed 0，保留各自输入和预算。
- 仓库内 49,076 字节的 `nlco_e003_seed0_20s.json.gz` 索引验证了 780 题标准模型一致性及 10,920 条既有评分的预测模型哈希关联。索引 SHA-256 为 `f4385be31fc5a5a27ffb04b07938d64e90354b9eca39bef5edf01ec4ca106110`。原始证据见 E003-1.1 双轨归档。只有确无兼容旧评分时才补算固定设置下的标准模型结果。
- DCP-Bench 沿用完整 E005-1.17 的六个传统求解器、无后训练、常见后训练及 B/C/S/P/Q 反馈对照，连同 E005-1.18 已完成组从旧报告引用。新加 B 和 C 使用当前选定的建模器，以便同输入比较。官方模型轨道和生成模型轨道分别解释。

## 再测改进方案

只用 NLCO 90 道冻结原训练题及其衍生题。24 道验证题和全部测试题都保持在训练之外。DCP-Bench 159 题使用已定主测定义。两个建模起点和对照来自此前已经观察过的队列，本轮属于有历史暴露的配对复测。

1. **建模后训练**。沿用 180 道旧端点钳制增广题，再从训练原题的 p-bit 可行状态中构造最多 90 道目标扰动题。把新目标明确写进题面，只保留能用两份可行解核验目标顺序变化的样本。两套建模器分别从各自冻结起点继续训练。原题两遍、增广一遍，局部 token 加权，锚定各自起点的参考分布，学习率 2.5e-6。
2. **反馈后训练**。训练独立 LoRA 输出局部补丁或修复无效初稿。训练标签来自原题正确模型和经核验反例。推理先读 p-bit 探测状态和初稿残差，提出目标、约束或逻辑块补丁。对有效初稿，三种能量响应共同选择钳制位点，先检验有无区分见证，再用原题裁判和双复核决定是否采纳。修编译与有效补丁分别记录。新反馈分别应用于旧、新建模器。
3. **能量惩罚控制后训练**。在同一状态和同一随机流上比较固定、针对易违反约束加罚、减罚及重分配。每次只改探索半群的权重，保护半群按原策略搜索。训练比较原模型可行性和目标下的归档解，打平时使用群体质量提供辅助监督。动作按观测支持和大于 0.05 的相对分数决策。若没有符合阈值的训练样本，报告控制未训练。评测并列同动作集中的规则控制、学习惩罚控制及固定降温。

建模、反馈、惩罚三个改动各自有配对行，完整组合相对冻结多能量 p-bit 组合和双复核组合比较。每条 p-bit 终端均为 32 链、128 更新步热身和 4 个 128 更新步控制窗，总计 20,480 次热浴尝试（固定变量模型除外）。扰动训练、反馈探测和 LLM 调用计入各自开销，惩罚写入另报。NLCO 终端搜索用种子 17；DCP-Bench p-bit 用 17、29、43，SCIP 用 17。原题评分复用标准模型，保留可解析、语义状态、可行、最优、gap 及有效分母。配对区间 5,000 次重采样，NLCO 按题，DCP-Bench 按模板，不作多重调整。
