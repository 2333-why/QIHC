# E005-1.6　用 p-bit 采样轨迹后训练能量修订模型

方案阶段，尚无本轮训练或性能结果。基点 d7e2b40c，分支 codex/e005-four-methods。关联 [E005-1.4 四方法](E005-1.4_record.md) 和 [E005-1.5 反例来源诊断](E005-1.5_record.md)。本轮单独建档。

## 研究问题

同一实例、同一初始能量、同一批探针样本，给 Qwen3-32B 看各约束的违反频率和搜索进展，能否比只看最好解更有效地选择下一次能量修订，使新的独立 p-bit 搜索在固定计算量内更常找到原题最优解？首轮学习一次修订。进一步的“只看题面直接输出权重”是另外的部署问题，可在有增益后蒸馏。

## 动作与正确性

固定数学模型、变量编码、归一化目标和温度。模型输出约束 ID 与惩罚权重修改，允许原样保留。当前实现的能量为有符号归一化目标加各约束归一化违反量平方的加权和。默认权重均为3。所有可行状态的惩罚为零。当前整数编码下目标经 objective_scale 归一化后绝对值至多1；每个正的归一化违反量至少1。因此，对于存在可行状态的这些模型，全部权重严格大于2足以让任一不可行状态能量高于任一可行状态。该界是充分条件，实施时校验整数域、归一化和有限数值；改变目标缩放或残差定义需要重新验证。小题穷举作实现交叉检查。

训练题上比较统一权重 2.25、3、4.5、6，择优固定基础权重。主实验只允许最多两对约束间转移权重，每次总和不变，所有权重至少2.125且至多8；每次转移0.125、0.25、0.5或1。按合法动作解码。这样保持平均惩罚尺度和温度一致，测试的是如何分配权重。某些背包题只有一条约束，这种情况只允许保留；单列可调整子集，全部题仍进分母。若需要学习整体尺度，则另开与调温对照的实验。这里学习的是软件残差能量，不自动得到二次 Ising 哈密顿量或物理硬件速度结论。

## 输入、监督和推理

1. 给定公开题面、带稳定约束ID的模型和初始权重。32链，三个温度0.25/0.5/1，每温度每链128次单点更新作诊断。记录固定步号32/64/96/128的状态，分温度与链保存；原始轨迹留盘，模型只读固定长度摘要。
2. 摘要包括最好可行解及其目标、每温度的可行比例、每条约束的违反频率与平均违反幅度、前后半段状态多样性及可行目标的分位数。不可行样本也保留。摘要超过预算时按固定规则选频繁违反和几乎从未违反的约束，并保留稳定ID。只提供部署时根据输入模型可算的量，参考最优值、测试 gold 和候选修订后的成绩只供评分。链内样本相关，统计按题、种子或独立链进行。
3. 训练题上构造至多8个不同动作，含保留、固定规则和均匀抽取的合法改动，所有对照共享候选与标签。相同起态和随机数流，分别进行每链512次更新；按独立复测种子记录成功率。用取得已证最优解的独立运行比例做主排序，同分时只在可行率一致且双方均有可行解时比较已证参考gap。其余同分或跨种子方向不一致记作无明确偏好，保留计数。仅对达到预先冻结的最小差异门槛的候选做偏好训练。先做输出语法与合法动作 SFT，再用 DPO 学习择优；两训练组父模型、偏好对、步数和输出格式相同。
4. 测试时从公共基础权重出发，只跑一次短探针、一次LLM修订、一次新的长搜索。模型不能试多个修改再按测试成绩挑选。无效修改回退到原权重，并计入失败率。正式评价用新种子，与诊断、挑选标签和验证种子互斥。

现有 search.summarize 默认构造 Energy(spec)，其代表性状态已去重且至多16个。实现时用真实权重重算各样本的能量，保留出现次数；从固定步号采样，关闭可能提前截断的时间预算或显式记录截断。重复快照不可当作新链。不同权重下的绝对能量不用于比较质量。

## 四组最小对照

| 组 | 可见信息和决策 | 对应问题 |
|---|---|---|
| A | 统一权重，在训练集选好后固定 | 一个全局参数是否已经够用 |
| B | 全分布摘要，固定规则调整权重 | 简单规则能否利用相同信息 |
| C | 题面、模型、初始能量和同一探针的最好样本，后训练LM修订 | 最好解能提供多少信息 |
| D | C的全部输入加分温度分约束的轨迹摘要，后训练LM修订 | 分布信息能否提供额外收益 |

B预设规则：提高最高违反率约束的权重、从最低违反率约束转移相同量，平局按ID；转移量只在训练题选择，信息不足或越界则保留。C/D均允许保留，提示模板、模型、长度上限与训练数据一致。默认权重3额外作廉价历史锚点。主比较 D-C，次比较 D-B 和 D-A。另在验证集上对同一 D 模型遮去分布字段，核查模型是否实际使用轨迹。若要主张 p-bit 特异性，再以同等更新预算和相同摘要字段替换轨迹来源，保持后续求解器为 p-bit。这个消融不要求重开 Metropolis-DPO 实验。

按等总采样更新数比较。A可将探针预算用于直接搜索，其他组可保留探针期的可行解，统一返回探针与最终搜索的最好合法解；另报告仅最终搜索结果。主表记录是否在总预算内命中。模型推理和摘要处理耗时完整计入端到端耗时，另以20秒全系统预算复测能否保留优势。E004的20秒终端求解计时不含LLM开销，按其原口径另列。每题每种子一条主要结果，链或时间片不当独立题。

## 规模、放行与论文边界

| 阶段 | 数据与安排 | 预先约定的决定 |
|---|---|---|
| CPU先导 | 锁定NLCO六族90训练题/24验证题，按E005-1.4的split。训练题选统一参数；验证24题比较规则、全局和逐题选择的机会。用独立种子块分别选候选、复测，报告候选覆盖、可调整题数、命中天花板和有效偏好题数 | 建议工程门槛：至少30/90训练题有稳定偏好；24验证题上的逐题候选选择经独立复测，相对统一参数提高至少3个百分点。均达标才投入四卡。这是资源决策，24题不作正式显著性结论 |
| 正式后训练 | 同一共享环境/Qwen3-32B/4×H100 80GB/24CPU；C/D各用训练种子17/29/43。SFT及DPO仅使用90道训练题。以验证集选公共超参，测试前冻结 | 记录LoRA版本、有效原题数、偏好对数、候选采样成本、训练GPU时和四组端到端成本 |
| 主测与规模迁移 | 冻结E004主测480题，同一标准模型输入四组。300道L题为规模迁移。主指标为固定预算内已证最优命中率，次指标为原题可行率、首次最优步数（未命中记删失）、共同可行子集gap和耗时。单列有已证参考的题数。按原题配对bootstrap并报告区间 | D优于C才支持轨迹信息的额外价值；D优于B才支持使用LLM的额外价值。若各组全满分，报告饱和。增加更大公开实例或缩短预算均须另行冻结协议 |
| 端到端迁移 | 在相同题上读取E004同一份冻结M0；再在同一份P2最终模型上复测。学生只读取该输入模型及可见轨迹，原题标准模型仅用于评价。原先编译失败保留在系统分母 | 此阶段仅改变求解能量，数学模型完整正确率理论上不变。只声称解质量或预算效率变化 |

建议先导种子分区：诊断101–104，训练候选初评201–204，独立复测301–308；正式评价401–408。每种子的具体实例/链流由稳定哈希生成，所有方法共享。以90题×8候选×12个初评/复测种子为上限，共8640次候选运行，每次32链×512更新，约1.42亿次单链单点更新，另计短探针和验证。先以6题实测吞吐估算核时，再决定排程。
