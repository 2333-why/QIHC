## 3. 求解质量：标准模型轨道

gap 为相对已证明最优值的目标偏差，越低越好：最小化用 `(解值−最优值)/max(1,abs(最优值))`，最大化反向。下表均已乘 100，单位为 **%**。先对每题五个种子平均，再对 900 题平均；本轮记录完整，等价于对 4,500 次运行平均。

| 求解器 | 所有预算可行率 | 1 秒 gap | 5 秒 gap | 20 秒 gap | 20 秒最优值命中率 |
|---|---:|---:|---:|---:|---:|
| CP-SAT | 100% | 0.00677% | 0% | 0% | 100% |
| SCIP | 100% | 0% | 0% | 0% | 100% |
| HiGHS | 100% | 0% | 0% | 0% | 100% |
| SA 模拟退火 | 100% | 0.11626% | 0.03589% | 0.00868% | 99.62% |
| PT 平行回火 | 100% | 0.12584% | 0.03865% | 0.00828% | 99.58% |
| penalty-PT | 100% | 0.13946% | 0.03989% | 0.01162% | 99.42% |
| p-bit | 100% | 0.17031% | 0.05233% | 0.01388% | 99.33% |

“最优值命中率”由返回解与独立最优参考比较得到，不代表采样算法自己给出最优证明。20 秒下 p-bit 为 4470/4500 次命中；885/900 题五个种子全部命中；900/900 题至少一个种子命中。最后一项使用每题五次各 20 秒运行，不能表述成单次 20 秒 100% 最优。

在 20 秒设置下，CP-SAT 有 4495/4500 次自行证明最优，另外五次返回值也经独立参考核实为最优；SCIP、HiGHS 均为 4500/4500 次证明最优。

## 4. 时间与成本

| 求解器 | 1 秒上限：平均实际求解耗时 | 20 秒上限：平均实际求解耗时 |
|---|---:|---:|
| CP-SAT | 0.0523 秒 | 0.1838 秒 |
| SCIP | 0.0156 秒 | 0.0195 秒 |
| HiGHS | 0.0252 秒 | 0.0292 秒 |
| SA / PT / penalty-PT / p-bit | 约 1 秒 | 约 20 秒 |

这些是接口记录的求解墙钟时间，包含相应建模转换，不包含完整进程启动和 LLM 生成成本。采样器按预算运行到结束，精确求解器能在证明最优后提前退出；因此不能把 20 秒直接解释为采样器首次达到最优所需时间。当前数据显示精确求解器能非常快地完成这些实例，p-bit 没有展示运行成本优势。后续比较应增加统一目标质量下的首次到达时间。

本实验所有七个求解器均在 CPU 上运行。p-bit 是软件随机采样仿真，没有真机功耗测量，不能推导 p-bit 硬件节能优势。包中只有 188 个 LLM 模型的生成成本：累计输入 790337 tokens、输出 450921 tokens、222 次尝试、归属生成时间 37703.6 秒；该值不覆盖全部 900 题，也不是多 GPU 作业总历时，不能用作整轮成本。

## 6. 可以汇报与不能汇报的结论

| 判断 | 本轮证据 |
|---|---|
| 通用 p-bit 仿真可以求解这六类小规模二进制组合优化问题 | 支持：完整 900 题、三预算、五种子，100% 可行，20 秒平均 gap 0.01388% |
| 实验执行与统一评测已获得完整的求解器轨道结果 | 支持：94500 条原始解复核通过，无执行错误 |
| p-bit 优于 SCIP / HiGHS / CP-SAT | 不支持：精确求解器更快且解质量更优或相同 |
| p-bit 优于 SA / PT / penalty-PT | 不支持：p-bit 三个预算的整体平均 gap 均更大 |
| LLM+p-bit 能正确理解并求解公开自然语言问题 | 尚不能判断：LLM 轨道没有评分 |
| 分布反馈、约束干预、能量策略选择或后训练有效 | 本轮未检验：配置未启用这些消融/训练，p-bit 使用共享能量上的基础单比特随机更新 |
| 已达到全 NLCO 或大规模求解器测评范围 | 不支持：本轮是 43 类中的六类，900 题，最大 30 个二进制决策变量 |

本轮的合理定位是**完整的小规模公开基准与实现正确性证据**。要证明算法独特优势，需要在保留强精确求解器对照的前提下，继续测更大、更难的实例，以及完整反馈闭环；不能通过去掉强对照或只报告少量胜例得到优势结论。
