# E004-1.1 对 E003-1.1：端到端提升与反馈归因

日期：2026-11-01，Asia/Shanghai。状态：对比工具已实现，E004 正式指标待返回。本补充不修改已准备/正在运行的 E004 采样、数据、预算或方法组别；只读聚合旧实验与本轮公共题集结果。仍归属 E004-1.1。

## 实验目的

检验“相同 LLM 初始模型 + p-bit 主动反馈闭环”能否比“相同 LLM 一次建模 + 传统求解器”更准确地回答原始自然语言优化问题。追求原题质量的真实改善，不通过筛去失败、删除约束、只选有利任务或缩短对照预算保证胜出。

E003 已有结果提供起点：20 秒、五种子下，LLM 轨道原题可行率为 CP-SAT 35.80%、SCIP 35.11%、HiGHS 35.29%、p-bit 36.29%；全量最优值命中率分别为 11.13%、11.11%、11.00%、11.20%。它们不是 E004 的结果，也不是新增三种子配对后的指标。[原始完整分析及证据](../E003_public_solvers/E003-1.1_analysis_20261101.md)。

## 设置与比较

| 比较 | 控制内容 | 可支持的结论 |
|---|---|---|
| U2 vs E003 七后端，LLM 初稿、20 秒轨道 | 同 900 题、同冻结初稿、共同种子 0/1/2；保留全部无效初稿 | 额外反馈闭环是否改善端到端回答；有额外计算与 LLM 成本 |
| U2 vs C0 | 同初稿、题目、非 LLM 预算 | 比单纯继续搜索是否更有效；不能单独排除额外 LLM 调用收益 |
| U2 vs C1 | 相同调用上限和非 LLM 预算，自审组不看搜索证据 | 主动反馈是否超过仅增加 LLM 自审 |
| U2 vs C3 | 相同闭环框架与预算 | 受控探针与自适应选择是否超过被动分布反馈 |
| U2 vs B1 / B2 | 相同反馈框架/预算，后端改为 Metropolis / SCIP 条件池；如实披露能力适配差异 | p-bit 适配的反馈是否存在额外价值 |
| E003 canonical 七后端 | 正确标准数学模型、独立展示 | 求解器参照；不是和自然语言端到端闭环完全同信息的比较 |

E004 的 1200 个扩展实例没有相应 E003 结果，仅用于 E004 内部比较，不与 900 题公开集混算。无需重复运行 E003 七后端全矩阵。报告默认 U2 为主方法，不依据正式结果重新挑选主方法。

## 指标与判读

| 指标 | 定义 | 作用 |
|---|---|---|
| 原题可行率 | 满足原始约束的次数 / 全部指定次数 | 检查约束满足能力；不等同于语义理解正确 |
| 最优值命中率 | 原题可行且目标达到已证明原题最优值 / 全部指定次数 | 本轮所称的求解“准确率” |
| 质量达标率 | 原题可行且相对已证明最优值 gap≤5%，另报≤1% / 全部指定次数 | 联合衡量可行性和目标质量，尤其避免 MAXCUT 的高可行率误导 |
| 配对 gap 差 | 双方同实例同种子均可行时的 gap 差，先按实例平均 | 辅助衡量质量；必须同时报告覆盖范围 |
| 修复/回退 | 相对对照，从不可行变可行、从可行变不可行的次数 | 披露反馈收益与损伤，不能只报修复 |
| 额外成本 | 调用、输入/输出 tokens、记录到的推理/搜索时间、未知成本项 | 防止把额外计算带来的质量提升说成免费优势 |

共同种子重新聚合后才能配对，不直接将 E004 三种子百分比减去 E003 五种子汇总。报告未完成时，全量分母率只是下界，配对结果是描述性快照，不能作为完整正式结论。

原题可行率和 gap≤5% 质量达标率是重点，最优值命中率与 gap≤1% 同时披露。正向点估计只说明观察到提升；区间、校正后检验和各任务表现用于判断是否稳定。只有对 C1、B1/B2 等受控比较也有支持，才进一步讨论 p-bit 反馈的额外价值；只胜过 E003 一次建模不足以证明 p-bit 比传统求解器本身更强。不得保证实验必然优于对照。
