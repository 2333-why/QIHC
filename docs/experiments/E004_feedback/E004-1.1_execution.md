## 固定实施细节

- 四张 H100 **80GB**，默认每卡一个 Qwen3-32B 副本、batch=1，四路真实推理；不是旧方案的两个双卡副本。真实显存与上下文容量由 GPU 验收检查，未在本机声称跑通权重。
- 沿用既有 conda 环境及权重。脚本直接指定项目 Python；联网 CPU 不承担正式搜索。准备时复用已有隔离格式/求解器依赖，不升级共享 torch/transformers。
- 数学模型、源文本、配置、依赖版本各有身份校验。结果与历史 E003 彻底分开；不得在正在跑的工作树 `git pull` 后继续混用。
- 默认调度为开发调试 60 题 → 开发验收 60 题 → 公开 900 题 → 扩展 1200 题。开发每题十二组、一个种子，1440 条；正式 56160 条，总计 57600 条。
- 路由系数预设 `[0.35, 0.30, 0.25, 0.10]`，基于分歧、稳定性、新信息、成本；缺少合法假设或分数接近时均分。没有用正式测试反馈更新路由参数。
- 事件触发子实验目前节省的是**补丁调用**；审阅已发生时照实计费，不声称跳过整个双调用轮次。它检验实际调用成本—质量折中。
- SCIP 使用原生硬约束，不能把改变惩罚伪装成同一热浴采样。因此 M3 返回明确的能力缺失，U2 将后续配额分配给可用探针；M1 是目标扰动/多样解池的行为适配，报告不冒充温度概率。SCIP 得到原生求解状态和界。
- 有界域修订可通过局部编辑执行，但两个解释域不一致时，不在不相容状态空间比较 q；记录此类假设供源文本审阅。修改域后丢弃超出新域的 warm start 和候选，再在新模型下评分。
- 扩展图规模 32/64/128/256，图结构稀疏度随机变化，边/非边最多 460，遵守通用 IR 的 512 条源约束上限。不是覆盖任意高密度大图。MCP 以非边表示稠密图，与 MIS 存在互补转换，不能将两者视为完全不同的数学能力证明。
- 所有组同样保留搜索候选，并在模型更新后重新评价。C0 累积搜索结果，不只取最后窗口；C1 的记忆不包含任何搜索状态，C2 只获得一个候选及其当前模型指标。
- 20 秒/轮是非 LLM 核心计算预算，源码补丁编译扣减后续窗口；进程启动/导入开销另存 `cpu_execution_events`。生成耗时单列，同时纳入真实端到端时间。参考和统一 SCIP 诊断单独计账。
