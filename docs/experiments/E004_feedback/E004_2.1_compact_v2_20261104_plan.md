## 1. 目标与结论边界

**核心问题：在相同初始模型、原题信息和计算预算下，p-bit 的主动条件采样证据，能否比已有反馈方法更有效地修复建模错误，并提高最终解的质量？**

| 要回答的问题 | 对比方式 | 允许得出的结论 |
|---|---|---|
| 反馈有没有用？ | 反馈组对无反馈 C0、自审 S | 建模和端到端任务收益 |
| 反馈 p-bit 能否超过无反馈其他求解器？ | P2 修复模型＋p-bit，对 C0 初稿＋SCIP/HiGHS/CP-SAT 等 | 整套系统收益，不能归因于求解器本身 |
| p-bit 是否提供额外价值？ | 主测同协议对 SCIP、Metropolis、ReLoop/DRAGO；解析检查和 PT 留在机制轨道 | 有限预算下反馈机制/采样内核的增量 |
| 收益来自哪一部分？ | P0/P1/P2、随机钳制、固定卡片重放、消融 | 主动选择、分布证据和多温度的作用 |
| 结论是否可推广？ | 未调参任务族、公开题、中大规模、第二 LLM | 明确适用范围与失败边界 |

E004-1.6 中 P/X/M 修复的是同一道题，尚未证明 p-bit 独有优势。本轮不沿用“已经优于其他求解器”的前提。当前软件 pbit 与 Gibbs 共用 heat-bath 更新，因此研究对象先定义为 **p-bit 风格条件采样反馈**；没有硬件测试时不声称硬件加速、能耗优势或与 Gibbs 本质不同。

**新颖性调整：** ReLoop 已研究求解器参数扰动反馈，DRAGO 已研究确定性诊断修复，SAC-Opt 已研究语义锚点。不能把“反馈＋修模”“主动扰动”“来源片段”单独当创新。候选贡献是：预算内主动选择钳制探针、读取有限时间条件分布、形成可复算且能弃权的来源证据，并通过强替代内核证明增量。[ReLoop](https://arxiv.org/abs/2602.15983v6)、[DRAGO](https://arxiv.org/abs/2610.22568v1)、[SAC-Opt](https://arxiv.org/abs/2510.05115v3)。

## 2. 三种 p-bit 方案

| 方案 | 采样方式 | 输出证据 | 主要验证点 |
|---|---|---|---|
| P0：被动分布 | 固定温度，多链，不主动钳制 | 多个代表状态、来源冲突与频率 | 分布是否比单个解有用 |
| P1：主动条件 | 选择单变量/变量对，分别钳制采样 | 条件频率差、小反例、原文位置 | 主动探针是否更有效 |
| P2：多温度主动 | P1＋多温度响应，**总预算不增加** | 跨温度稳定证据、置信度、弃权 | 可靠性与诊断收益是否提高 |

P2 为预先指定主方法，禁止看测试成绩后改选主方法。惩罚权重扰动只作扩展消融；**用户定义的软约束偏好权重不能当搜索惩罚参数随意修改**。

| 环节 | 统一规定 |
|---|---|
| 来源检查 | 仅看原题和公共数据，盲于初稿与隐藏标准模型；每项有原文位置和可信度；检查本身也要评价正确率 |
| 候选探针 | 每轮至多 32 个动作，深入执行至多 4 个；含不钳制、单变量、变量对；由公开检查和候选模型依赖图产生 |
| 主动分配 | 前 25% 时间探索，后续按不同冲突收益＋探索项－重复惩罚分配；独立后续窗口确认，避免选择噪声自证 |
| 采样 | 初始 32 链；P2 温度 {0.25,0.5,1.0}，先统一能量尺度；参数仅在开发集冻结 |
| 证据预算 | 每轮 10 秒，包含编码、选择、采样、验证和卡片生成；最多 4 卡、总计 1024 token |
| 修改预算 | 2 轮，每轮 1 次 LLM 补丁调用；格式重试消耗该组既有预算；记录截断与超时 |
| 公共接受规则 | 所有组检查补丁格式、可执行性、确定性公共事实及可信回归检查；诊断方法的专有规则另外记录，不能访问金标准 |
| 弃权 | 只有采样异常、来源语义不明或无响应时不强行认定模型错误；记录覆盖率和弃权原因 |

采样得到的高温违例并不自动是建模错误。候选模型排斥某个状态也不证明原题允许该状态。条件频率是经验观测，已知能量差算出的 log odds 是解析量，两者分列。按链进行误差估计，报告重复状态和混合诊断；未证明收敛时只称有限时间响应。小规模用枚举分布校准，核对辅助位/整数编码的多重表示是否扭曲分布。

## 3. 精简主实验：只保留 7 组

| ID | 必须保留的对照 | 回答的问题 |
|---|---|---|
| C0 | 无反馈，同一初稿直接求解 | 反馈系统是否超过不反馈的纯求解器？ |
| S | 纯自审，2 次修补调用 | 收益是否只是多思考机会？ |
| X | SCIP 主动反例反馈 | 是否优于传统强求解器给出的反馈？ |
| M | Metropolis 主动反馈 | 是否只是通用随机采样收益，而非 p-bit 更新内核的作用？ |
| R | ReLoop-adapt | 是否超过近期主动扰动反馈方法？ |
| D | DRAGO-adapt | 是否超过近期确定性诊断修复方法？ |
| P2 | 多温度主动 p-bit | 本轮预指定主方法 |

X 保留多解、no-good 排除、钳制和违规搜索，不削弱成只输出单个最优解。M 与 P2 使用相同来源、动作、温度、卡片接口与总预算，只替换更新内核。R/D 为统一条件适配，不能称原论文完整复现；需要额外 LLM 诊断时从该组的 2 次调用额度扣除。R 参数扰动无响应时不能直接判定约束遗漏。

所有主组共享冻结 M0、公开来源信息、IR、修补器、确定性公共接受规则与回归检查。方法专有诊断另记，不能访问金标准。SCIP 使用公共反馈协议是必要公平对照；不应禁止强对照使用相同信息。

公开题候选仍为明确版本 CPBench、MAMO 离散 MILP、LogiOR 离散题及 RetailOpt 可支持子集。先按共同支持范围冻结，再分层选题；无法凑够 120 时报告实数，不用容易题暗中补齐。报告原始总量、unsupported 原因与覆盖率；CPBench 派生版本去重。公开工作流均使用同一 LLM，每题 C0 1 次、其余各最多 4 次调用，生成/来源提取/诊断/修补都包含在额度内。作者默认工作流受此限制时标成本适配；更换原生求解器同样标适配，不冒充完整复现。

## 5. 三条评价轨道不缩减

| 轨道 | 分母与指标 | 失败如何处理 |
|---|---|---|
| 端到端 | 全部计划实例；原题可行、已证最优命中、任务成功、时间/token | 建模、编译、超时、求解失败均保留，不能筛掉 |
| 建模质量 | 全部实例；完整正确率、错误修复、正确模型退化、初始失败恢复 | unknown 与已证错误分开，两者都不计已证明正确 |
| 固定模型求解 | 同一模型 hash 的可运行输入；gap、原题可行性、输入模型最优性 | input_invalid 显式列出，不把建模问题归为求解器失败 |
| 机制与成本 | 见证有效率、误报、来源检查正确率、弃权、首证据时间；全部实际资源 | 无卡片不算正确诊断；重试、编码、验证与失败成本都计入 |

完整模型正确仍要求：原始决策空间的可行集合一致，所有可行解的目标优劣顺序及并列一致。小题枚举验证，辅助变量作存在性投影；原始目标值与单位一致率单列。大题有限检查不能称完整正确；已证最优与 best-known 分开。真实不可行题以可核验证书衡量任务成功，另列分母。

### 5.1 求解器矩阵如何节省 CPU

| 模型集合 | 终端后端 | 保留的证据 |
|---|---|---|
| 全部主测最终模型＋每题 M0/GOLD | SCIP、p-bit | 960 题完整同模型比较；反馈收益与终端内核分开 |
| 全部 960 题 M0/GOLD | 再加 CP-SAT、HiGHS、SA、PT、penalty-PT | 无反馈七求解器全量基线与标准模型参考 |
| 预先分层选定 120 题的全部反馈最终模型 | 再加上述五后端 | 完整七后端交叉矩阵子集，不能冒称全量 |
| 全部 960 题 M0 | 七后端另给 20 秒搜索时间 | 对应 2×10 秒探针 CPU 预算补偿；记录同一连续搜索的 40 秒结果 |

七后端单次基础限时 20 秒，记录 1/5/20 秒 incumbent；终端用模型/实例稳定派生种子。M0 延长到 40 秒须是同一运行的继续，不重启择优；这是探针搜索时间补偿，不是全部 LLM/GPU 成本等价，资源分类报告。相同模型 hash 及配置可去重执行但保留轨迹映射。参考解证明过程另记成本。
