## 1. 区分真正可利用的特性与共享能力

| 对象 | 主要输出或计算方式 | 在反馈中的作用 | 必须公平承认的边界 |
|---|---|---|---|
| CP-SAT / SCIP 等精确求解器 | 搜索、传播或松弛/界；给可行解、求解状态，条件满足时给最优性或不可行证明 | 判断当前数学模型是否能解、界差如何；可在固定变量后重求解和构造多样解池 | 不是只能输出一个解；证明针对输入模型，不能证明自然语言被正确理解 |
| Metropolis / SA / PT | 根据能量变化接受候选；可保留轨迹、条件采样、调温和重加权 | 同样能形成分布、干预和冲突反馈 | 这些能力不专属于 p-bit，必须提供同等控制接口 |
| 当前 p-bit 仿真 | 按局部能量差直接进行热浴更新，可钳制部分变量、调节偏置/耦合 | 用局部条件概率和受控条件分布探测数学模型的响应 | 当前 `pbit` 与 `gibbs` 是同一更新分支；不能宣称软件 p-bit 优于同一 Gibbs 算法 |
| 未来 p-bit 硬件 | 若设备提供相应接口，可持续运行可调随机比特网络 | 将同一主动探针协议映射为钳制、偏置写入和状态读出 | 吞吐、功耗、有效独立样本率必须实测；本轮仿真不能证明硬件优势 |

核对位置：`qihc/generic/distribution/search.py` 的 `window`。现有实现尚无本方案完整的主动钳制和语义假设控制器。

**研究主张：利用可控概率网络主动询问一个数学模型“它究竟表达了什么关系”，把响应变成 LLM 的局部纠错证据。** 这比单纯反馈最优候选更契合 p-bit，但是否比其他采样器高效仍需实验。

## 2. 核心算法：语义假设—条件探针—局部修订

### 第一步：从原题形成少量待区分解释

LLM 先读取原题及变量映射，给出至多三个解释（必须包括保留原模型），定位到目标或约束因子。例如是“不同取值获得奖励”还是“同时选择获得奖励”，是“至多一个”还是“至少一个”。每个解释附原题引用和可执行局部公式。

这是通用表达层的候选解释，不按 KP/MAXCUT 等任务标签选择手写规则。假设提出和最终补丁仍受原方案每轮两次调用限制，不增加隐藏的 LLM 调用。

### 第二步：把局部概率作为可观测量

对二进制变量，在其余变量固定时：

`q_i = P(x_i=1 | x_-i) = sigmoid(-(E(1,x_-i)-E(0,x_-i))/T)`。

在仿真中可直接从局部能量差计算 q，也保留实际比特状态。q 表示当前数学模型的局部偏好，**不是原题正确概率，也不是网络的边缘概率**。高阶因子可通过局部能量差求值，不要求全部问题预先强制压成两两耦合；硬件实现另行核验编译与辅助变量成本。

局部 q 读出不是额外真值。Metropolis 等对照也允许计算相同 q，并把这部分计算计费，避免把信息权限不同误当成 p-bit 优势。

### 第三步：主动钳制，测量条件响应

选择少量存在假设分歧的变量或变量块，从共同起点分叉：固定为 0 / 1，允许其余变量继续波动，记录

`R_ji = mean(x_j | clamp(x_i=1)) - mean(x_j | clamp(x_i=0))`。

同时允许小幅偏置变化、目标局部项扰动、约束惩罚变化；保留基准分支。不要构造全体变量的 O(n²) 响应矩阵，只围绕分歧因子选择预算内的少量探针。

响应包包含钳制条件、改变的参数、候选状态、响应方向/幅度、跨链稳定性，以及对应原题引用。固定温度窗口用于诊断，优化阶段可以退火；样本有自相关，只能报告有限时间响应，不能未经混合检验称为平衡分布或因果发现。未观察到某状态不构成不可行证明。

选择准则优先考虑：**不同解释预测的条件响应分歧、估计稳定性、探针成本**。具体分歧度和权重在开发集锁定。不能单凭高熵选靶点，也不能通过隐藏原题检查器选择“最有效探针”。

### 第四步：LLM 对照原文，修改局部数学因子

先取得 LLM 对原题关系的解释，再展示当前模型和探针响应，减少直接附和。根据“原句—候选解释—实测模型行为”输出局部补丁，并在相同探针及预留探针上复测。

复测确认行为是否按补丁意图改变，**不证明补丁符合原题**。不能因某解释能量更低、可行质量更多而选它：漏约束通常也会使可行率变高。每个候选模型的尺度和温度需要统一约定；不同模型的原始能量不可直接比较。

只调整温度、偏置和搜索惩罚属于内层搜索控制；修改原始目标、约束或索引属于外层语义修订，必须分开记账。所有临时钳制和偏置在最终求解前恢复；更新数学模型后重新评价旧候选，保留旧版本及回退记录。

## 3. 一个能说明差异的推导例子

以下是**只有两个变量和一条边的理论示例，不是新实验结果**。题意为“两个端点分到不同组时得分”。

| 数学解释 | 最大化目标 | 固定 x1=0 后的 P(x2=1) | 固定 x1=1 后的 P(x2=1) | 条件响应方向 |
|---|---|---|---|---|
| 不同取值得分 | x1+x2−2x1x2 | sigmoid(1/T) | sigmoid(−1/T) | 负 |
| 同时为 1 得分 | x1x2 | 1/2 | sigmoid(1/T) | 正 |

这使反馈从“得到一个差解”变成“当前能量鼓励共同取 1，但原文要求不同取值”。E003 已观察到同类目标错误；本方案尚未证明能自动修复它。复杂网络中的间接路径和约束会改变响应，不能把本例的正负规则硬编码为通用判错器。

精确求解器也可以固定变量后比较两次求解；差别在于本方案研究的是有限预算下持续获得的条件概率响应，而不是声称其他求解器做不到反事实测试。

## 4. 与原十组实验衔接

F0/F1/F2/F3 保持冻结搜索、自审、单解、分布的含义。细化其余组：

| 组 | 修订后的定义 | 主要检验 |
|---|---|---|
| F4 | 分布＋随机探针；统一探针库包含钳制、偏置、目标项及惩罚扰动 | 任意干预是否已经足够 |
| F5 | 同一探针库；依据违约、耦合、波动信号选靶点，不用语义假设分歧评分 | 分布定向选择的价值 |
| F6 | 同一探针库；依据语义假设的条件响应分歧选择探针 | 主方法：主动获取建模纠错证据 |
| F7 | 与 F6 相同控制与信息权限，换 Metropolis 更新 | 热浴动力学是否带来质量—成本收益 |
| F8 | 与 F6 相同外层协议，用 SCIP 条件求解及多样解池提供候选 | 与传统优化反馈比较 |
| F9 | F6 的实例内错配反馈负对照 | 有用的是证据内容，而非单纯增加提示文本 |

F4/F5/F6 使用相同探针类别配额、分支数量上限、搜索/LLM 预算和补丁权限；主要区别是靶点选择。F4/F5 获得同样预算的候选解释文本，但选择器不读取假设分歧评分，避免 F6 单独多一次推理。F6−F5 不应解释成“钳制本身”的独立贡献，因为双方都有钳制。

新增一项**待确认的机制诊断子实验**：复用原定 120 个分层实例（开发阶段预先固定身份），只补 F6 去钳制、F6 去 q 读出两组，各三种子，共 720 条额外轨迹。释放的计算预算用于剩余探针；其他模块相同。若纳入，正式总量从 52200 变为 52920 条轨迹，最多新增 4320 次 LLM 调用、8847360 输出 tokens；单独列成本，不声称免费消融。去 q 组仍用热浴更新，只是不向诊断/选点提供 q 读出。

F8 不把优化解池频率冒充 Boltzmann 概率；将其报告为条件解池的经验响应。单独的同信息采样器比较主要看 F6/F7，F8 则比较各方法原生诊断在同预算下的实用效果。SCIP 状态、界等也应提供给其反馈组。

## 5. 可以支持什么结论

- 若 F6 比 F5 更好：支持“语义假设指导的主动探针”有用。
- 若 F6 比去钳制组更好：支持条件钳制提供额外信息；仍不是硬件独有能力。
- 若 F6 比去 q 组更好：支持局部概率读出有用；不能等同 p-bit 更新算法独有优势。
- 若 F6 稳定优于同接口 Metropolis，且等墙钟/等能量评估两种口径一致：支持当前任务和预算下热浴更新更适合该反馈协议，不能泛化为所有 p-bit 硬件更快。
- 若 F6/F7 相当：应将贡献归为通用概率网络反馈协议及 p-bit 实现，不宣称 p-bit 特有性能胜利。
- 只有真机测出包含编译、传输、采样、LLM 调用的端到端成本，才能讨论硬件能耗优势。

评价沿用隐藏原题可行率、质量达标率、目标排序一致性、修复/回退率及完整成本。新增记录：每个有效纠错证据的采样成本、响应跨链稳定性、局部 q 使用量、钳制次数。不能用这些内部指标替代原题正确性。

## 6. 依据与新颖性边界

- [Stochastic p-bits for Invertible Logic, PRX 2017](https://arxiv.org/abs/1610.00377)：已提出通过钳制部分位，让其余位在相容状态间波动。钳制、反向推断本身不是本项目创新。
- [OR-Tools CP-SAT 官方文档](https://developers.google.com/optimization/cp/cp_solver)：有多种求解状态及解枚举接口，不能把传统求解器设成“只有一个答案”的弱对照。
- 当前代码中 p-bit/Gibbs 的同一实现是本项目可直接核验的限制；不虚构一个不同的 Gibbs 基线。

拟议贡献集中在**自然语言歧义驱动的条件探针选择、模型响应的源句对齐、受预算约束的局部能量修订**。这是研究设计，尚未完成系统新颖性排重，也无本轮效果数据。
