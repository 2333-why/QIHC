## 1. 目标与结论边界

**核心问题：在相同初始模型、原题信息和计算预算下，p-bit 的主动条件采样证据，能否比已有反馈方法更有效地修复建模错误，并提高最终解的质量？**

| 要回答的问题 | 对比方式 | 允许得出的结论 |
|---|---|---|
| 反馈有没有用？ | 反馈组对无反馈 C0、自审 S | 建模和端到端任务收益 |
| 反馈 p-bit 能否超过无反馈其他求解器？ | P2 修复模型＋p-bit，对 C0 初稿＋SCIP/HiGHS/CP-SAT 等 | 整套系统收益，不能归因于求解器本身 |
| p-bit 是否提供额外价值？ | 同协议下对解析检查、SCIP、Metropolis、PT、ReLoop/DRAGO 适配组 | 有限预算下反馈机制/采样内核的增量 |
| 收益来自哪一部分？ | P0/P1/P2、随机钳制、固定卡片重放、消融 | 主动选择、分布证据和多温度的作用 |
| 结论是否可推广？ | 未调参任务族、公开题、中大规模、第二 LLM | 明确适用范围与失败边界 |

E004-1.6 中 P/X/M 修复的是同一道题，尚未证明 p-bit 独有优势。本轮不沿用“已经优于其他求解器”的前提。当前软件 pbit 与 Gibbs 共用 heat-bath 更新，因此研究对象先定义为 **p-bit 风格条件采样反馈**；没有硬件测试时不声称硬件加速、能耗优势或与 Gibbs 本质不同。

**新颖性调整：** ReLoop 已研究求解器参数扰动反馈，DRAGO 已研究确定性诊断修复，SAC-Opt 已研究语义锚点。不能把“反馈＋修模”“主动扰动”“来源片段”单独当创新。候选贡献是：预算内主动选择钳制探针、读取有限时间条件分布、形成可复算且能弃权的来源证据，并通过强替代内核证明增量。[ReLoop](https://arxiv.org/abs/2602.15983v6)、[DRAGO](https://arxiv.org/abs/2610.22568v1)、[SAC-Opt](https://arxiv.org/abs/2510.05115v3)。

## 2. 三种 p-bit 方案

| 方案 | 采样方式 | 输出证据 | 主要验证点 |
|---|---|---|---|
| P0：被动分布 | 固定温度，多链，不主动钳制 | 多个代表状态、来源冲突与频率 | 分布是否比单个解有用 |
| P1：主动条件 | 选择单变量/变量对，分别钳制采样 | 条件频率差、小反例、原文位置 | 主动探针是否更有效 |
| P2：多温度主动 | P1＋多温度响应，**总预算不增加** | 跨温度稳定证据、置信度、弃权 | 可靠性与诊断收益是否提高 |

P2 为预先指定主方法，禁止看测试成绩后改选主方法。惩罚权重扰动只作扩展消融；**用户定义的软约束偏好权重不能当搜索惩罚参数随意修改**。

| 环节 | 统一规定 |
|---|---|
| 来源检查 | 仅看原题和公共数据，盲于初稿与隐藏标准模型；每项有原文位置和可信度；检查本身也要评价正确率 |
| 候选探针 | 每轮至多 32 个动作，深入执行至多 4 个；含不钳制、单变量、变量对；由公开检查和候选模型依赖图产生 |
| 主动分配 | 前 25% 时间探索，后续按不同冲突收益＋探索项－重复惩罚分配；独立后续窗口确认，避免选择噪声自证 |
| 采样 | 初始 32 链；P2 温度 {0.25,0.5,1.0}，先统一能量尺度；参数仅在开发集冻结 |
| 证据预算 | 每轮 10 秒，包含编码、选择、采样、验证和卡片生成；最多 4 卡、总计 1024 token |
| 修改预算 | 2 轮，每轮 1 次 LLM 补丁调用；格式重试消耗该组既有预算；记录截断与超时 |
| 公共接受规则 | 所有组检查补丁格式、可执行性、确定性公共事实及可信回归检查；诊断方法的专有规则另外记录，不能访问金标准 |
| 弃权 | 只有采样异常、来源语义不明或无响应时不强行认定模型错误；记录覆盖率和弃权原因 |

采样得到的高温违例并不自动是建模错误。候选模型排斥某个状态也不证明原题允许该状态。条件频率是经验观测，已知能量差算出的 log odds 是解析量，两者分列。按链进行误差估计，报告重复状态和混合诊断；未证明收敛时只称有限时间响应。小规模用枚举分布校准，核对辅助位/整数编码的多重表示是否扭曲分布。

## 3. 主实验 12 组：共享初稿与信息

| ID | 方法 | 与 P2 的关键区别 |
|---|---|---|
| C0 | 无反馈 | 同一冻结初稿直接求解；单列额外求解时间补偿控制 |
| S | 纯自审 | 看原题、初稿和共享来源信息，自行检查；无工具诊断证据 |
| B | SAC-Opt 风格语义锚点适配 | 锚点对齐，无 p-bit 条件采样 |
| A | 解析检查 | 已知系数、索引、局部能量差及公共事实的确定性分析 |
| X | SCIP 主动反例 | 多个可行解、no-good 排除、钳制和违规目标；不能只给 SCIP 单个最优解 |
| M | Metropolis 主动反馈 | 与 P2 同动作、来源、温度与卡片接口，替换更新内核 |
| T | Parallel Tempering 主动反馈 | 相同信息与总时间，计入交换及多温度开销 |
| R | ReLoop-adapt | 求解器参数响应、执行诊断与修补；统一 IR 和预算的适配版本 |
| D | DRAGO-adapt | 确定性诊断与有证据的修补；统一任务和预算的适配版本 |
| P0 | 被动 p-bit | 无主动钳制 |
| P1 | 主动 p-bit | 无多温度证据聚合 |
| P2 | 多温度主动 p-bit | 本轮主方法 |

R/D/B 是适配方法，不标成原论文完整复现。主实验统一冻结 M0、检查信息、IR、补丁接口、2 次修补调用、卡片长度与 CPU 预算；方法需要额外 LLM 诊断时从其 2 次调用中扣除，不能暗中增加调用。R 的参数修改必须合法，无响应可能来自非活跃约束，不能直接判断约束遗漏。

外部系统比较另设原生工作流面板，保留作者结构化生成方式与求解器要求；明确区分“统一条件机制比较”和“原生系统比较”。SCIP 可以使用同样的公共反馈协议，这是排除“只是协议好”的必要对照，不应人为禁止。

| 轨道 | 计划规模 | 配置与作用 |

| 消融 | 主测预选 240 题 | 6 额外配置×3 种子×2 轮，不增加独立题数 |
| 第二 LLM | 主测预选 240 题 | 6 组×3 种子×2 轮；另一模型家族，权重待冻结 |
| 公开基准 | **目标 200 题，实数待审计** | 9 工作流×3 种子；仅在预先定义共同支持子集上配对 |
| 固定卡片重放 | 主测预选 120 题 | 4 来源卡片版本×1 种子×2 轮，隔离卡片与求解器的影响 |
| 人工审计 | 主测 100＋公开 100 | 两人独立标注、争议复核；人员待落实，未做不能称已验证 |

主测构成：720 题来自 KP/MIS/MVC/MAXCUT/MCP/MDS 六族（各 120）；240 题来自加权集合覆盖、加权 MaxSAT、广义指派、离散时间排程（各 60）。新四族不参与调参。全体按直接表述、实体索引、量词边界、跨句业务条件四种语言难度分层，各 25%；每个独立实例只有一个主表述，改写不扩充独立样本量。

数据须新生成并按实例/模板来源去重，历史 E003/E004 数据仅用于开发和回归。原始决策位数与编码后总位数分别记录；辅助变量要做投影等价验证，不能以总能量最优代替原题正确。

机制轨道的八类注错：约束遗漏、方向反转、边界/量词、索引集合、系数绑定、变量域、目标方向、目标项遗漏；若注错对某题无语义影响则剔除并按预设规则补足。十方法为 A/X/M/T/R/D/P0/P1/P2/QuAcq 风格主动查询。查询对照只能获得同等公开信息；带真实 membership oracle 的版本单列上界，不能混作无真值方法。

规模扩展六组：C0/A/X/开发集预先选定的最佳非 p-bit 组/P1/P2，去重后空位按开发排名补齐并冻结。第二 LLM 六组：C0/B/X/开发集最佳非 p-bit 非重复组/P1/P2。最佳组仅按开发集选，不按测试结果选。

公开题候选为 CPBench 的明确版本、MAMO 离散 MILP、LogiOR 离散子集、RetailOpt-190 可支持子集。CPBench 派生/澄清版本去重，不能当多个独立数据集。连续变量、ODE、不支持的逻辑和编码过大的题须列出覆盖分母与原因，禁止为了凑 200 题偷偷换容易题。SoftOR/ASTOR 软偏好验证为独立可选面板，不进入本轮基本预算。

## 6. 指标：建模失败必须计入

| 评价轨道 | 主分母 | 主要指标 | 失败处理 |
|---|---|---|---|
| 端到端系统 | 所有计划测试实例 | 原题可行率、达到已证最优比例、任务成功率、总时间/token | 生成失败、编译失败、超时、求解失败都保留，不能删除 |
| 建模质量 | 所有实例；另列初始失败子集 | 完整模型正确率、错误修复率、正确模型退化率、初始失败恢复率 | unknown 与已证错误分开；两者均不计入“已证明正确” |
| 固定模型求解 | 同一可运行模型和模型 hash | 原题可行性、目标 gap、输入模型最优性、时间 | 不可运行模型标 input_invalid；不归因为某个求解器失败，汇总仍展示数量 |
| 反馈机制 | 全部探针/卡片/来源检查 | 见证有效率、诊断 precision/recall、正确模型误报率、弃权率、首次有效证据时间 | 无卡片不当正确诊断；来源检查错误单列 |
| 成本 | 所有实际尝试 | token、调用、CPU/GPU 秒、能量评估数、总耗时 | 重试、失败、编码、卡片验证均计入 |

**完整模型正确**：在原始决策空间上，候选模型与标准模型的可行集合一致，并且对所有可行解的目标优劣排序（含并列）一致。主测用枚举和目标值分组核对，避免逐对比较；原始目标数值/单位一致率另列，允许排序等价不等于数值正确。辅助变量先做存在性投影。外部大题只有有限测试时标“通过已执行检查”，不能标完整正确。

必须同时列出 `initial_invalid → executable`、`initial_wrong → correct`、`initial_correct → wrong`、`unknown`，避免只看最后可执行率。正确率报告实例均值，不把 3 个种子当 3 道独立题。

七个终端后端：CP-SAT、SCIP、HiGHS、p-bit、SA、PT、penalty-PT；固定模型各运行 20 秒，记录 1/5/20 秒 incumbent。每个冻结模型均交叉求解；M0 和标准模型每题各只存一份，不重复计算 C0 的相同模型。终端基准每模型一个确定派生种子；额外随机种子敏感性实验另计预算。纯求解器获得反馈阶段相同额外 CPU 时间的控制也单列，避免仅靠增加计算量获胜。

最优命中只能用已证明最优参考；只有 best-known 时称 best-known 命中，gap 明确参考。真实不可行公开题用可核验证书评价任务成功，不能在“找到可行解”指标中误罚；相应分母单列。

## 7. 消融与统计

| 项目 | 预先规定 |
|---|---|
| 六个额外消融 | 随机钳制；只保留最佳状态；去掉来源锚点；去掉不确定性/弃权；来源检查注错 10%；注错 30% |
| 卡片重放 | P2/X/R/D 产出的卡片分别输入同一修补器；终端固定，比较证据来源，避免把下游解算差异混入 |
| 主要指标 | 960 题最终完整模型正确率，先在题内平均 3 修补种子 |
| 五个主要比较 | P2 对 R、D、X、A、开发集从 B/M/T 选出的最佳组；Holm 控制多重比较 |
| 区间与检验 | 以实例为簇配对 bootstrap 10000 次；配对置换检验；报告百分点差、区间和校正 p 值 |
| 分层报告 | 任务族、四类语言难度、初稿是否可执行/正确；种子和错误类型分析作为次要结果 |
| 功效 | 960 为计划量，不保证显著；粗略独立配对二元近似下，5pp 差、discordance=0.2、双侧 α≈0.01、80% 功效需约 935 题；若 discordance=0.4 则约 1870。用开发结果做簇级模拟后、测试解盲前冻结 |

无显著差异不能写成等价；若只能证明多状态反馈有效，而不能超过 M/T/R/D，应如实收缩贡献。不得看到部分赢家后提前结束正式测试。因资源调整样本数须在解盲前更新记录及预算。
