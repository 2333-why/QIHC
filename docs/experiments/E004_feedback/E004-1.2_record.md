## 实验目的与判定

快速筛查反馈 p-bit 是否改善原题端到端解，并超过 E003 相同初稿上的其他求解器结果。另以同反馈 SCIP 区分反馈收益与 p-bit 后端收益。正确数学模型上的 canonical 结果是参考上限；不能把修订模型的收益称为 p-bit 纯求解能力领先。已达最优的实例最多打平正确的精确解，不应期待超过已证明最优值。

主要指标为原题最优值命中数、原题可行且 gap≤5% 数、可行数；逐题记录修复/回退和胜平负。不能只比较各自可行子集平均 gap。18 题是探索性筛查，不作稳定领先、全任务显著性或论文最终结论。

## 设置

- 数据：从 E003 的六任务 × 三难度共 18 个 dataset 层各取 1 题。按 `SHA256("20261102\0" + case_id)` 排序取首项，不读取性能或模型有效性选题；无效初稿照样保留。E003 已观察，属于回顾性公开数据筛查，不是未见测试。
- 具体 18 个 case_id 已在查看其表现前按上述规则冻结于[选题清单](E004-1.2_selection_20261102.json)，变量数范围 5–25；清单来自已回传的 E004 公共元数据，准备时从 E003 原数据按同规则重算。
- 组别：C0 无反馈 p-bit；C1 纯自审+p-bit；U2 自适应反馈+p-bit（主方法）；B2 相同反馈协议+SCIP。复用同题 seed=0、20 秒的 E003 七后端 llm_typed_flat 与 canonical 评分，不再推理/求解这部分。
- 18×4×1=72 条轨迹；种子 0；2 轮，每轮 base/probe/final=4/10/6 秒，最多 40 秒非 LLM 核心计算/轨迹；32 链；统一事后 SCIP 5 秒诊断另计。
- 审阅输出 2048、补丁输出 4096 tokens；每条最多 4 次调用/12288 输出 tokens。三种修订组共最多 216 次调用、663552 输出 tokens；C0 无调用，复用初稿不新生成。
- 限制审阅最多一个替代假设、每补丁最多四个编辑；逻辑表达式最多四层运算、每个 and/or 最多八项，not 一项、implies/iff 两项；各组接口一致。保留原模型、通用数据引用和全部题，不做题型专用修复。
- 累计输入预算 131072、单次输入 32768；反馈包仍为 4096。单次输入容量不增加，避免扩大 KV 显存；输入超限/输出截断照实记失败，不静默截断原题。
- Qwen3-32B，四卡单卡副本、batch=1，12 个在途轨迹、24 CPU worker。沿用原环境和权重，不下载或升级；真实硬件与依赖按准备/运行证据登记。
- 对 E003 20 秒轨道属于“额外 LLM 修订及额外搜索预算后的端到端比较”；C0 控制 40 秒搜索，C1 控制 LLM 自审，B2 控制同反馈后端。只优于历史基线不足以证明 p-bit 优势。
