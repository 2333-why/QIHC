## 假设与改进

| 改进 | 机制 | 本地证据 | 尚需验证 |
|---|---|---|---|
| 审计和执行分离 | 缺 domain/引用注释记审计警告；变量与模型数学合法性独立检查 | v1 的 11 个缺 domain 计划可继续；错误上下界仍拒绝 | 后续目标和约束能否正确生成 |
| 类型明确的数据引用 | 按原题数据提供真实列名、向量/矩阵区别、源 ID 和嵌套 schema | 非法列与向量 flatten 被拒绝 | 实际生成失败率、延迟与成本 |
| 显式编号映射 | column+offset 或 index_of，严格检查未知/重复标识和越界 | 4 个真实越界样本使用显式映射后可构造正确目标向量 | 模型能否选择语义正确的映射 |
| 局部纠错 | 在原失败步骤上原子替换允许的数学字段，其他内容保留 | 缺列样本局部修复、非法补丁拒绝、检查点重放 | 同等额度下是否优于整步重试 |

以上不按题型套用公式，数据描述根据当前问题的字面数据适配。没有采用“超出下标就自动减一”或“看到某题型就填标准能量”的修复。

## 对照与设置

| 组 | 用途 |
|---|---|
| legacy_flat | 保留原版一次建模原文、旧编译和宽格式约束 |
| audit_staged | 原版分步提示，只分离说明审计与执行检查 |
| typed_flat | 完整类型接口的一次建模 |
| typed_staged | 完整类型接口的分步建模，整步重试 |
| typed_staged_local | typed_staged＋局部字段纠错 |

配对：legacy_flat→typed_flat、typed_flat→typed_staged、audit_staged→typed_staged、typed_staged→typed_staged_local。第一项测试整个接口组合，不称为纯提示词消融。审计分离与旧 legacy_staged 的比较使用失败样本回归证据，历史 GPU 数据不当作本轮同步对照。

数据沿用既有 NLCO 240＋合成 60，无新增下载；这些样本已有调试接触，不称为全新盲测。先 8 题执行验收，再 300 题正式评测。模型路径继承旧数据准备 manifest，预期 Qwen3-32B，thinking=false。

生成预算：总输出 16384、最多 8 次调用、最多一次纠错；flat 单次 8192，staged 单次 6144；输入最大 32768，不静默截断。相同 schema 步骤但剩余输出额度不同的请求不合批，以防预算互相截短。实际总 token、调用数、失败耗时仍有差异，全部报告。

求解预算：CP-SAT 单线程 5 秒；p-bit 种子 0/1/2、16 链、每链 8192 候选评分。无搜索反馈、无后训练。四卡 80 核任务内运行两个双卡模型副本、每副本 batch 2、32 CPU 搜索进程。双方后端预算不是等 FLOPs。
