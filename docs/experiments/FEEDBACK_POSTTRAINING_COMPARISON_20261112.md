# 反馈、后训练与传统基线结果对比

更新：2026-11-12（Asia/Shanghai）。范围：截至本次已收到的实验记录与报告；本文不启动训练，也不将未返回结果视作完成。

## 1. 结论速览

- **以780题等权合并的原题最优命中率为主指标：当前最好的基座反馈是无采样双复核C，28.57%；我们的主动p-bit反馈Q为27.95%。** 两者均未做后训练。Q与仅修编译基线打平，不能称主动p-bit反馈优于传统反馈。
- **我们最好的后训练方法是P-VCD：p-bit终端约42.34%，SCIP终端约43.20%。** 最新完整480题主测+300题规模汇总取代旧216题子集作为总体比较依据；最新逐题审计、配对显著性仍待返回。
- 无反馈、无后训练的SCIP流水线为27.56%；SFT+p-bit约40.69%，Solver-RL+p-bit约41.43%，SDPO+p-bit约40.75%。主要跃升来自后训练；P-VCD在SFT之上的增量较小，规模集未稳定领先。
- 已有传统求解、传统反馈、常见后训练的可用对照，并非只有我们的方案。它们的完成范围不同，不能全部当作780题全量结果。

## 2. 统计口径与重要指标

主测480题、规模300题，共780道独立原题；不加入含训练题的120道开发题，也不加入仅10题的CP-Bench补充集。大多数反馈/后训练组主测每题3种子、规模每题2种子；旧C0部分结果每题1种子。

```text
先在每道题内平均其种子结果，再对题目等权平均：
R_780 = (480 × R_main + 300 × R_scale) / 780
对于主测3种子、规模2种子且全部齐全的组：
R_780 = (main成功轨迹/3 + scale成功轨迹/2) / 780
```

**不能用(主测成功轨迹+规模成功轨迹)/(1440+600)替代780题平均。** 所有失败保留分母。百分比差值使用“百分点”。反馈2.6由整数计数计算；后训练1.8只收到一位小数百分比，合并值均为近似值，展示两位小数不代表原始精度提高。不能由汇总百分比计算有效的配对置信区间。

| 指标 | 含义与用途 |
|---|---|
| 可执行/可编译率 | 数学模型通过接口并可运行；不等于语义正确 |
| 完整正确率 | 模型与原题的完整语义被验证正确；不随终端求解器改变 |
| unknown率 | 验证器暂不能判定完整语义；不是正确，也不等同编译失败 |
| 原题可行率 | 求出的赋值满足原题约束，按原题而非生成模型核验 |
| 原题最优命中率（主指标） | 赋值原题可行且达到已证明参考最优；按全题分母统计 |
| SCIP终端成绩 | 用同一最终数学模型换终端求解器，帮助分离建模和求解贡献 |
| 修订接受/恢复/退化 | 检查反馈或训练是否真正改变输出，以及是否损伤原有正确模型 |
| 调用、tokens、搜索与训练成本 | 分项记录；相同终端20秒不等于相同全系统成本 |
| gap、训练GPU小时、推理总墙钟 | 本轮关键来源缺统一可比全量值，不编造；需逐题原始结果/遥测补齐 |

除明确标注固定更新轨道外，表中终端求解均为20秒预算。不同实验的训练/反馈计算成本不匹配；跨轮对比是描述性系统比较，不能直接归因为某一机制。

### 6.4 方法含义、监督来源和已有比较

| 方法 | 实际做过的训练 | 可以检验什么 |
|---|---|---|
| SFT | 公开训练题面→标准数学IR的监督学习 | 后训练基础收益 |
| Solver-RL | SFT出发，候选由SCIP求解，按原题可行/最优奖励更新；组相对单步策略梯度 | 求解结果奖励是否超过SFT；不直接改称标准GRPO复现 |
| SDPO-IR | 编译/训练语义反馈条件下的同策略教师，逐token KL自蒸馏 | 反馈式后训练基线；统一IR适配，非原论文完整复现 |
| P-VCD（我们） | p-bit反例、独立验证、教师修复、正确修复蒸馏及语义奖励 | 当前最有希望的建模后训练候选 |
| pair_rl | 求解奖励与赋值可行/目标排序语义奖励结合 | 更密集语义奖励是否有效 |
| pair_local | pair_rl基础上增加验证后的局部修复蒸馏 | 局部修复信号是否有效 |

基础训练题和标准模型来自公开数据，不是p-bit生成；P-VCD用p-bit搜索反例，修复由LLM生成且独立验证后才入训练。已有P-VCD的提升包含SFT、语义奖励及蒸馏，缺少“同损失同预算、只把反例生成器换成SCIP”的完整后训练对照，不能把全部增益归因于p-bit。

E005-1.7按原题配对bootstrap：SFT相对旧P2的主测最优+18.68个百分点，95%区间[15.28,22.36]；Solver-RL相对SFT +1.25，区间[-0.21,2.71]。这些是旧轮主测统计，不是最新780题统计。旧P-VCD 85.0%来自216题共同子集，不能进入780主表，也不能和50.8%的完整主测解释成性能下降。

### 7.2 后训练1.8：输出变化

| pair_rl | 15 | 17 | 23 | 2 |
| pair_local | 15 | 18 | 24 | 3 |

均为题目—种子轨迹计数。“无效恢复”只要求可编译，不要求语义正确；“正确退化”未包含正确→invalid/unknown，二者不可相减当净修复。报告中局部补丁接受=0属于在线反馈字段，在后训练组不适用，不能据此声称训练修复为0。已审计旧P-VCD训练：540训练组中137组发生奖励更新，641候选产生证据，26次修复通过验证并蒸馏；事件可重复同一题。最新新增训练组的同口径明细仍待trace。[S3][S4]

## 9. 哪些已经可以比较，哪些还缺

| 比较目的 | 已做过、可用的方法 | 当前边界 |
|---|---|---|
| 我们的方法 vs 传统求解 | SCIP、CP-SAT、HiGHS、SA、PT、penalty-PT | 480题完整；780全量目前只有SCIP/p-bit可列 |
| 主动p-bit反馈 vs 传统反馈 | 纯自审、SCIP搜索反馈、Metropolis反馈、来源/执行诊断、参数扰动、编译修复、双复核 | 分开2.2与2.6；S/M/D等不是780全量 |
| P-VCD vs 常见后训练 | SFT、Solver-RL、SDPO-IR | 有完整主测/规模汇总；后两者是项目适配实现，成本未严格匹配 |
| P-VCD机制消融 | pair_rl、pair_local；旧P-VCD训练事件审计（见核心结果汇编） | 增量收益与机制归因仍待独立对照 |
| 后训练后是否还需反馈 | SFT、compile、scip_local、pbit_local | 主测319共同题的部分比较，不能填780全量 |
| 搜索过程是否可学 | 统一/规则/最好样本/轨迹能量策略，动作SFT→DPO | 已做但未见收益；新分段控制1.11暂无性能 |
| 标准GRPO、独立数学建模DPO、PPO | 本批没有可直接引用的独立正式成绩 | 不以Solver-RL或能量DPO替代命名 |
| p-bit是否带来独有后训练优势 | 需要同损失同预算，仅更换SCIP/随机/Metropolis反例来源 | 当前未有完整后训练配对，不能下此结论 |

推荐汇报主表保留：传统SCIP、原始p-bit、编译修复B、双复核C、主动反馈Q、SFT、Solver-RL、SDPO、P-VCD；另列同模型SCIP终端。完整正确、可行、最优必须同时展示。当前最稳妥的表述是：**后训练带来较大的系统改善，P-VCD在780合并点估计上最好；单独反馈的收益较小，主动p-bit的额外优势尚未建立。** 最新780题的配对显著性仍待逐题数据验证。
