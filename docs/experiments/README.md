# 实验记录索引

从 2026-10-26 起，每轮实验在本目录下单独建立文件夹，记录设置、运行过程与结果。
使用 [记录模板](TEMPLATE.md) 创建 `YYYYMMDD_实验名称_版本或run-id/record.md`。
同配置续跑追加原记录；实验配置变化时建立新目录并相互关联。
