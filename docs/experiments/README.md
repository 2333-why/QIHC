## 编号约定

- 大实验按类型编号：E001、E002、E003……。
- 当前 prompt、建模接口、分步建模和语义纠错统一归入 **E001（prompt）**。
- 迭代从 **E001-1.1** 开始，依次为 **E001-1.2、E001-1.3**；同类改动不增加大实验号。
- 不同类型的新实验使用新的大实验号；E002 已分配给共享 LLM 建模的求解器比较，首轮为 **E002-1.1**。
- 同类迭代直接保存到大实验目录的 `E001-1.4_record.md` 等文件，不新建日期/版本文档目录。同配置续跑和新结果快照沿用原迭代号，保留旧证据。
- 文档编号与历史代码版本、run-id 建立映射；归档不重命名正在运行的入口、工作树和服务器结果。
