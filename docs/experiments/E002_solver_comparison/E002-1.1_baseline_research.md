# E002-1.1 基线调研与适配决策

日期：2026-10-28（Asia/Shanghai）。问题范围：有限有界整数/二进制变量、整数系数线性约束、二次目标、布尔逻辑；不宣称覆盖任意连续优化或任意自然语言问题。

| 基线 | 意义与来源 | 本轮实际实现 | 可比边界 |
|---|---|---|---|
| CP-SAT | 通用离散约束求解强基线；[Google 官方说明](https://developers.google.com/optimization/cp/cp_solver) | OR-Tools，整数变量、逻辑及乘积约束 | 同一预测数学模型；不是把 gold 直接提供给该主表基线 |
| SCIP | 现代通用 MIP/CIP 强基线；[SCIP 10.0 报告](https://arxiv.org/abs/2511.18580)、[官方项目](https://www.scipopt.org/) | PySCIPOpt 6.3.0；与 HiGHS 共用精确二进制 MILP 转换 | 这是固定转换后的 SCIP 表现，不代表穷尽 SCIP 原生非线性建模与调参能力 |
| HiGHS | 开源 MILP 求解强基线；[官方能力说明](https://ergo-code.github.io/HiGHS/stable/) | highspy 1.15.1；二次项精确线性化 | HiGHS 不原生支持整数 QP；本轮明确转换成 MILP，不直接调用 MIQP |
| SA | 成熟随机局部搜索控制，检验收益是否仅来自通用随机退火 | 单比特 Metropolis、16 链、共同退火曲线 | 与 p-bit 共用初始化、编码、残差能量及解档案规则 |
| 温度 PT | 跨温度交换改善局部搜索；与近期通用 ILP 随机求解研究方向一致 | 固定温度梯度、Metropolis 更新、相邻副本交换 | 自实现参考算法，不是原论文复现 |
| 惩罚 PT | 直接比较跨约束惩罚强度探索是否有价值 | 不同惩罚系数副本、正确联合能量交换概率 | 同样是参考算法；不含论文的 locally-balanced 多步提议 |
| p-bit | 本项目随机比特更新机制 | 单比特 heat-bath 更新、16 链、共同退火曲线 | CPU 仿真基础内核；本轮不含 LLM 搜索反馈、硬件或后训练 |

近期相关工作：[Solving Integer Linear Programming with Parallel Tempering（2026 预印本）](https://arxiv.org/abs/2605.29366)，[作者代码](https://github.com/ski-sim/ILP-with-ParallelTempering)。论文包含更具体的提议机制；当前实现只用温度/惩罚交换思想建立可审核控制，不能冠以“论文完整复现”或引用其成绩作为本轮成绩。正式论文比较可在后续迭代接入其原版并验证相同问题范围。

不把“最新”作为唯一选择标准：CP-SAT、SCIP、HiGHS 提供成熟且强的通用离散优化对照；SA/PT/惩罚 PT 更适合识别 p-bit 更新机制的独立价值。

| 暂不纳入主表 | 原因 |
|---|---|
| Gurobi / COPT | 用户当前无许可证；不以缺失方法冒充已运行基线 |
| ReEvo / EoH / LLMCoSolver | 改变 LLM 的建模/生成流程，不满足本轮“相同冻结 LLM 模型”的控制变量；用户此前暂缓原版复现 |
| [Simulated Bifurcation](https://github.com/bqth29/simulated-bifurcation-algorithm)、[D-Wave QUBO 采样器](https://docs.dwavequantum.com/en/latest/ocean/api_ref_samplers/) | 主要接口为 QUBO/BQM；当前通用 IR 还包含整数和逻辑。直接塞进主表会额外改变惩罚、松弛变量及表示。后续可以在共同精确 QUBO 子集单独比较 |

所有主表后端先读同一模型；CP-SAT 的原题参考解在独立 CPU 评分路径计算，绝不返回给建模或求解器。新依赖隔离安装，不升级现有 Torch / Transformers。
