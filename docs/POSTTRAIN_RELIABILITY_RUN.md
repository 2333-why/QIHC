# 单卡后训练修复实验

## 启动

在联网 CPU 节点更新代码：

```bash
cd /inspire/hdd/global_user/czxs25210022/why/qihc && git pull --ff-only
```

向平台的一台 worker、一张 H100 80GB 作业提交以下一行命令：

```bash
bash /inspire/hdd/global_user/czxs25210022/why/qihc/scripts/run_posttrain_overnight.sh
```

脚本自动激活现有 conda 环境，复用本地权重；首次更新后离线校验原模型、数据、环境并运行单测和微型真实训练，再迁移准备清单。无需下载模型或重跑第一步。需要至少 60 GiB 空闲显存。不要和正在运行的正式任务共享一张卡，也不要在旧任务仍读取此目录代码时更新同一 checkout。

默认实验时间上限 24 小时（不含前置校验），不是完成时间承诺。可在启动命令前加 `QIHC_OVERNIGHT_HOURS=36` 延长。超时保存已有文件并返回非零；再次运行会建立新目录，不会自动断点续跑。

## 实验设置

| 项目 | 本轮设置 |
|---|---|
| 模型 / 硬件 | Qwen3.5-9B / 单 H100 80GB，LoRA + ZeRO-3 |
| 规模 | 100、200、300 客户，各 36 个实例，共 108 个 |
| 划分 | 按几何分组：72 训练、18 验证、18 测试，互不重叠 |
| 教师 | 72 训练实例 × 2 搜索种子 × 最多 6 轮，最多 864 条轨迹 |
| 测试 | 18 个独立实例 × 2 搜索种子，共 36 个配对作业 |
| 相同搜索预算 | 每作业 3 轮、512 链、80 步、top-64、destroy 12、每客户 4 路线 |
| 初始化 | 所有组复用相同中性 p-bit 初始解 |
| SFT | 120 步，学习率 2e-5；至少 288 条邻域监督、360 条总监督 |
| DPO | 学习率 1e-6，beta 0.2，附加 0.2 权重的 chosen-answer NLL；有效 batch 4，最多 40 步且不超过一遍数据 |
| 数据门槛 | DPO 至少 64 对执行验证后的邻域偏好；不足则明确失败，不重复复制凑数 |

四组为纯 KNN+p-bit、原始模型+p-bit、SFT+p-bit、正则化 DPO+p-bit。KNN 组不加载 LLM；各组使用同一约束输入与搜索配置。这里对齐的是搜索次数/采样预算，不是相同运行时间或能耗。p-bit 为软件采样，并非 FPGA 真机。

## 本次修复与验收

旧版训练序列按字母排序，把 logits 放在客户与路线前面，与推理要求相反；本版统一为客户、路线、紧凑整数 logits、confidence，去掉调试字段。chosen/rejected 使用相同格式，量化后的实际答案重新执行验证，不沿用量化前奖励。去除完全相同的偏好对，过滤超过推理输出预算的训练答案。

旧轮只有 20 对偏好而训练约 6 遍。本轮扩大教师覆盖、降低学习率、限制数据遍数，并显式监督正确答案以减少格式退化。这是针对代码风险的修复，是否消除实际 9B 输出失败须由本轮实测确认，不能由微型训练替代证明。

验证集严格模型输出率至少 95%，且 DPO 不得比 SFT 下降超过 2 个百分点。截断恢复、补客户、完整 KNN 回退均不算严格模型成功。无论门槛是否通过，仍保留原始 DPO 测试结果，不会偷偷换成 SFT 后标作 DPO。失败类型、输出末尾示例、截断次数、回退次数单独输出。门槛失败标记 `complete_quality_gate_failed` 并返回非零，不能视作实验崩溃或合格模型。

输出：`results/posttrain_overnight_<时间>/summary.json`，日志：`logs/overnight-<时间>.log`。摘要包含相对原始模型和相对纯 KNN+p-bit 的配对成本变化、可行率、胜负数及验证集可靠性。平均百分比是逐作业改进率的平均，不等于平均成本之比。

本轮仅检验邻域后训练，不含 GRPO 训练、LLM 冷启动能力评测、硬件能耗结论或多训练种子统计显著性结论。
